# FIT-Log — Workout Library & Personal Training Planner

> **Plan your workout. Track your progress. Stay consistent.**
>
> FIT-Log is a modern workout management application where users can explore exercises, create a daily workout plan, save their favorite workouts, and monitor important workout statistics from one place.

---

## 🚀 Live Demo & Repository

* **Live Website:** https://fitness-activity-check.vercel.app/
* **GitHub Repository:** https://github.com/priyaahmed007/Fitness-Activity-Check.git

## 📖 About the Project

**FIT-Log** is designed to make workout planning simple and organized. Users can browse a collection of exercises, view detailed workout information, add exercises to their daily plan, and save workouts for later.

The application focuses on a clean dark-themed interface with a straightforward user experience, allowing users to manage their workouts without unnecessary complexity.

---

## 🌟 Main Features

### 1. 🏋️ Exercise Library

* Browse a collection of different workout exercises.
* Each exercise is presented with useful information such as:

  * Exercise image
  * Exercise name
  * Target muscle group
  * Required equipment
  * Duration
  * Calories
  * Rating
* Search for exercises quickly using the search functionality.
* Filter exercises based on muscle groups.
* Responsive card layout adapts to different screen sizes.

---

### 2. 📊 Workout Statistics

FIT-Log provides useful workout information through dynamic statistics.

Users can keep track of:

* Total selected exercises
* Total workout duration
* Estimated calories
* Saved exercises

The displayed numbers update automatically whenever exercises are added, removed, or completed.

---

### 3. 📝 Daily Workout Plan

Users can build their own workout routine by adding exercises to **Today's Plan**.

* Add exercises directly from the exercise details page.
* Limit the daily workout plan to a maximum of **5 exercises**.
* Prevent additional exercises from being added once the limit is reached.
* Remove exercises whenever necessary.
* View the current workout plan in one dedicated section.

This keeps the daily workout focused and easy to manage.

---

### 4. 📋 Exercise Details Page

Each exercise has its own detailed page.

The page includes:

* Exercise image
* Exercise name
* Target muscle group
* Equipment information
* Difficulty level
* Sets and repetitions
* Workout duration
* Estimated calories
* Rating
* Exercise description
* Step-by-step instructions

Users can also add the exercise to their daily plan or save it for later directly from this page.

---

### 5. 💾 Save Workouts for Later

Users can save exercises that they may want to use in future workouts.

The saved section allows users to:

* View saved exercises
* Remove saved exercises
* Quickly return to an exercise
* Keep their preferred workouts organized

---

### 6. 🔄 Manage & Complete Workouts

The workout plan provides simple controls for managing exercises.

Users can:

* Mark an exercise as completed
* Remove an exercise
* Sort exercises
* Switch between the daily plan and saved workouts
* See updated workout statistics instantly

Completed exercises are visually distinguished so users can easily see their progress.

---

### 7. 💡 Smart User Feedback

FIT-Log provides instant feedback when users interact with the application.

Toast notifications are used for actions such as:

* Successfully adding an exercise
* Saving an exercise
* Removing an exercise
* Completing a workout
* Reaching the daily exercise limit

This helps users understand the result of each action without interrupting their workflow.

---

### 8. 📱 Responsive Design

The interface is designed to work across different screen sizes.

The layout adjusts for:

* Desktop
* Tablet
* Mobile

Exercise cards, navigation, workout details, and plan management sections remain accessible and easy to use on smaller screens.

---

### 9. ❌ Custom Not Found Page

FIT-Log includes a custom **404 / Not Found** page that matches the application's overall design.

If a user visits an invalid route, they receive a clear message along with an option to return to the main application.



## 🎯 Project Goal

The main goal of FIT-Log is to provide a simple and visually organized platform for discovering exercises and creating a manageable daily workout routine.

Instead of keeping workout information scattered across different places, users can explore exercises, create a plan, save workouts, and track their session from a single application.
